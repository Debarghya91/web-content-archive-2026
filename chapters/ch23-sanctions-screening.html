Sanctions Screening

Learner applies sanctions screening to payments, explains list types, false positives, and hit handling, and writes a clear disposition for a screening alert. Learner demonstrates this skill using realistic banking examples, explaining each step clearly and using correct terminology throughout.

Sanctions screening in payments: how banks check every payment against OFAC, UN and EU lists, and what happens when a name matches.

What You Can Do After This Chapter

Learning objective. Learner applies sanctions screening to payments, explains list types, false positives, and hit handling, and writes a clear disposition for a screening alert. Learner demonstrates this skill using realistic banking examples, explaining each step clearly and using correct terminology throughout.

Practical assessment. Learner screens five payment records against a sanctions list extract, identifying two true hits, two false positives, and one clear payment, and writes a disposition for each with the evidence used. Learner then explains the difference between a name match and a confirmed match, and states the escalation path and the hold action for a true hit. Learner submits the work with all calculations, sources, and assumptions stated clearly, and checks the result against the chapter checklist before final submission.

Expected deliverables.

  • Screening results table for five records
  • Disposition notes with evidence per record
  • False positive versus true hit explainer
  • Escalation and hold procedure

Completion criterion. Learner classifies at least four of five records correctly, justifies each disposition with evidence, and states the true hit escalation path correctly. Completion is judged on accuracy, completeness, and clear reasoning throughout the submitted work.
