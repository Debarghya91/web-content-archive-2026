Reject and return in CBPR+: pacs.002 and pacs.004, the rules that decide everything.

What You Can Do After This Chapter

Learning objective. Learner explains reject and return in CBPR+, describes when pacs.002 is mandatory for a final negative status, and shows how pacs.004 works as a separate settlement instruction. Learner uses real amounts, banks and message names to show how reject and return work in practice.

Practical assessment. Learner receives a case where a USD 250,000 CBPR+ payment from London to New York is rejected for a wrong account, then drafts the pacs.002 rejection, the pacs.004 return with a different return amount and charges, and a note on the Return Chain and on INDA and INGA reason handling. Learner also explains when a negative camt.029 answer is allowed and which codes it may carry.

Expected deliverables.

  • pacs.002 rejection draft for the USD 250,000 payment
  • pacs.004 return draft with charges and return amount
  • Return Chain diagram for the correspondent route
  • Note on INDA and INGA and on final negative status rules

Completion criterion. Learner drafts a correct pacs.002 and pacs.004 with accurate amounts, charges and reason codes, and explains the Return Chain and INDA and INGA clearly. and the Return Chain explanation is accurate and complete.
