ISO 20022 Course

ISO 20022 is the new global language for payments. This course teaches it the way migration projects need it: read and write the messages, map MT to MX, explain CBPR+, and validate XML against its schema, all with real examples.

What you will learn

  • Read SWIFT MT messages field by field.
  • Read and write ISO 20022 messages (pacs.008, pain.001, pain.002, camt.052, camt.053, camt.054, camt.060).
  • Map MT messages to ISO 20022 and explain CBPR+ migration.
  • Validate an ISO 20022 XML file against its schema.
  • Handle rejects and returns with pacs.002 and pacs.004.

Chapters in this course

  • ISO 20022 Fundamentals (12 lessons). The new global language for payments, and why it matters.
  • pacs.008 Deep Dive (8 lessons). The customer credit transfer in ISO 20022, block by block.
  • MT to MX Migration and CBPR+ (14 lessons). Coexistence, translation, truncation and readiness.
  • Payment Data Model and Mapping (7 lessons). From channel to settlement: one canonical model.
  • Complete ISO 20022 Catalogue (13 lessons). Every message a payments professional must know.
  • Reject and Return in CBPR+ (8 lessons). pacs.002 and pacs.004: the rules that decide everything.
  • pain.001 and pain.002 in Depth (10 lessons). From customer instruction to status report.
  • ISO 20022 Technical Implementation (8 lessons). How the standard is built, read and validated in real systems.
  • SWIFT MT Messages (19 lessons). The classic SWIFT message types, field by field.
  • SWIFT Fundamentals (18 lessons). SWIFTNet, message types and the BIC.
  • MT101 in Depth (7 lessons). How corporations instruct banks to pay.
  • Documentary Collections and SWIFT Category 4 (7 lessons). Getting paid with documents, not promises.
  • SWIFT Reporting Messages Deep Dive (10 lessons). Statements, balances and confirmations, field by field.
  • MT103 Optional Fields Deep Dive (8 lessons). 52a, 57a, 53B, 70 and 71G: the fields that change everything.

Course 3, Messages: SWIFT MT, ISO 20022 and Standards, has 14 chapters and 149 lessons in total.

Tools and practice

Look up 27 MT and ISO 20022 messages field by field in the Message Explorer. Practise mapping in the ISO 20022 Mapping Workbench and the ISO 20022 Message and Mapping Lab with 14 exercises in valid and invalid XML. Keep the MT to ISO 20022 Mapping reference and the MT103 to pacs.008 Reference open while you work.
