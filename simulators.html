Simulators

Run a payment through the machine. Each simulator is a real working model on its own page, not a video. Pick one and run it.

Payment Lifecycle SimulatorOne payment, USD 25,000, London to Singapore. Follow it stage by stage, reference INV-8841. Cross-Border Payment ConfiguratorBuild a cross-border payment and watch the chain, the charges, and the final amount change. Payment Hub Architecture SimulatorEighteen components, in payment flow order, from the channel where an instruction arrives to settlement. ISO 20022 Message ExplorerReal structured XML examples for the seven messages that carry a payment from instruction to statement. T2 and TIPS SimulatorSettle a euro payment in T2 RTGS or in TIPS and watch the states change. Payment Accounting SimulatorEvery payment is a set of ledger entries, and every entry must balance. Payment Exception Investigation SimulatorTwenty-one exceptions, as operations sees them. Read the symptom, pick the first investigation step. Payment State Machine SimulatorOne payment, USD 25,000, London to Singapore. Watch its state change at every step. API PlaygroundReal payment API requests and responses. Send a valid request and an invalid one to see how validation and errors work. Scenario SimulatorWalk a payment going wrong, step by step: what happens, in which system, and how it gets resolved. ISO 20022 Message and Mapping Lab14 ISO 20022 message and mapping exercises with valid and invalid XML.
