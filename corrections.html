Corrections Policy

How to report an error on Payments Training Hub, how it is checked, and how the fix is recorded.

How to report an error

Report an error through the Contact page. Include three things: the address of the page with the error (copy it from your browser), what is wrong, and the source that shows the correct position (for example the scheme rulebook, the message standard, or the official guidance). A report that names the source is checked first, because it can be verified directly.

Errors in the following are treated as the highest priority: a wrong message field or field meaning, a wrong amount or currency rule, a wrong settlement or value date rule, a wrong charge or fee rule, and a wrong answer in a test or exercise. Errors in wording, examples and links are fixed in the same way but do not block a lesson.

How a report is checked

Every report is checked against the authoritative source documents listed on the Sources page. A correction is made only when the source confirms it. If the source is ambiguous, or if two sources describe the same subject differently, the lesson is updated to state which source it follows and to note the difference where it matters, rather than picking one silently.

Where a correction affects a concept that appears in other lessons, the same concept is checked across the curriculum, so the same error is not left standing elsewhere.

How a fix is recorded

Verified corrections are fixed in the lesson and the chapter review date is updated, so the fix is dated on the page itself. The correction is logged with the date it was fixed, the page it affected, and the source that confirmed it. The log is kept with the curriculum records and is used when a lesson is next reviewed, so a corrected error is not reintroduced.

Corrections that change a test or exercise answer are fixed in the test as well as in the lesson, so the lesson and its assessment always agree.

What is not a correction

A difference of opinion about how a subject should be taught is not an error, and it is handled as a suggestion rather than a correction. A request to add a topic is a suggestion for new content, not a correction. Suggestions are welcome through the same Contact page.
