Technical Business Analyst

Technical depth for BAs: message structures, APIs, integration patterns and testing, with the integration landscape first.

121Core lessons
16Chapters
10.0Hours of narration
5Simulators

Who this is for

A business analyst who writes interface specifications, validates messages and works with engineering teams.

Experience level: Working BA, 3 to 8 years, technical. A BA who writes interface specifications and works with engineering.

What you will be able to do

  • Write interface specifications and validate messages against schemas.
  • Design API contracts and integration patterns for payments.
  • Test and certify a payment integration end to end.

Prerequisites

The Business Analyst pathway, or equivalent BA experience in payments.

Work through the chapters in this order. Within each chapter, complete the core lessons listed.

Capstone: Integration specification

Design an integration for a real payment flow.

Deliverable: An integration specification: an OpenAPI contract for a payment API, a message mapping for one payment type, and a test pack covering the happy path and the main failures.

Completion criteria

  • Finish every core lesson in the sequence.
  • Pass the APIs, Messaging and Architecture tests with 70% or more.
  • Complete the required simulator and lab exercises.
  • Submit the integration specification.
